# 项目进度

## 目标

实现 Chrome Extension (ChatFree) 通过本地 HTTP Server 调用 Windows SendInput API，完成 AI 平台的自动粘贴与发送。

```
Chrome Extension → HTTP POST JSON → input_server.exe → SendInput → 浏览器
```
